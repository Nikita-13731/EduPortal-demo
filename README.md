Project Description 
<br>
Main Features: User friendly and responsive design (HTML5 + CSS3 + JS)
<br>
A website that help student to learn code and develop their skills.
<br>
A responsive and student friendly portal focused on learning coding, aptitude, reasoning, and tracking study progress through a to-do list app.
Sections for: Coding & Programming (interactive learning links/resources) Aptitude & Reasoning, CBSE Notes and Textbooks. Built in To Do List App to track daily study goals. Simple Study Guide/Progress Tips feature. Secure front end design principles (input validation, localStorage security, sanitization).
